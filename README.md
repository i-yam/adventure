# Adventure Capitalism

Twelve classes. Three pitch days. Students carry startup ideas across the term and stand in front of a room that behaves like it has money and reasons not to hand it over.

These are the lecture notes. They run a classroom, and they work alone if you have no classroom.

## What you are looking at

The course is a static site. Every page is one HTML file that opens on its own, in a browser, from a disk, with no server and no build step. If you cloned this repo and double-clicked a file, it renders the way students see it.

Nine classes carry material. Classes 04, 08 and 12 are shark tanks, where students pitch and the room pushes back, so they carry no pages.

Published so far: Classes 01 through 09. The rest of the syllabus is below and not yet written.

## How to read a class

Each class is a folder, `class-01/` through `class-12/`. Open the folder and `index.html` is the contents. It lists the parts, with the time each one takes and whether AI is recommended on it.

The parts are `module-01.html` onward, usually four to a class, around two hours end to end. One module is one task. It finishes with something you can hold up: a list of ten people to talk to, a retention curve, a price, a slide. That artifact is the input to the next module. Work them in order or you will feel the hole two modules later, which is the intended punishment for skipping.

Later classes lean on earlier work by name. Class 07 asks for the deck from Class 03, the retention curve from Class 05, and the pricing from Class 06. If you skipped them, you will notice.

## The tags

Every page carries the same five tags in the mono rail under the headline, and the same values in a `meta` line in the head for filtering.

| Tag | Values | Means |
|---|---|---|
| `interest` | product, customers, fundraising, sales, ops, finance, mindset | which part of building this page serves |
| `comfort` | no-code, some-code, builder | how much technical fluency it assumes |
| `time` | 15min, 45min, deep | attempt to estimate the work, not the reading |
| `track` | core, deep-dive | main line or optional depth |
| `ai` | off, on | whether you should use a model on this task |

This course is mostly `no-code` deliberately. You can do all of it with a notebook, a phone, and people willing to talk to you.

## Where the material comes from

Two houses teach this field and they do not agree. 

[Y Combinator's Startup Library](https://www.ycombinator.com/library) says launch now and talk to users. 
[a16z](https://a16z.com) says the market is the only thing that matters, and a great team in a dead market still loses. 
Both are right. The pages show the argument instead of blending it into a gray average.

The books behind the course: Ben Horowitz, *The Hard Thing About Hard Things*. Ilya Strebulaev and Alex Dang, *The Venture Mindset*. Brian Christian and Tom Griffiths, *Algorithms to Live By*. 

Everything linked here belongs to the people who wrote it. The pages send you to the source rather than quoting it at length.

## Doing this without a classroom

Read the class hub, then work the modules in order, and actually talk to the ten people. The reading takes an evening a week.

The pitch days are the part that needs other humans. Find three people who will interrupt you and ask them to be unpleasant for fifteen minutes. A friendly audience teaches you nothing you can use.
